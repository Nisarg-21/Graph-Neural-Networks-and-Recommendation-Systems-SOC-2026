# Q4 Part 4: Why deep GCNs over-smooth

Every GCN layer swaps a node's features for an average of itself and its neighbors. One layer blends a node with whoever sits right next to it. Two layers and that average quietly reaches one hop further, pulling in the neighbors of the neighbors. After $K$ layers a node's vector is really an average spread across everything within $K$ hops of it.

On a connected graph like Cora those $K$-hop neighborhoods start overlapping heavily once $K$ gets big. Most nodes end up averaging over roughly the same wide patch of the graph, so their vectors keep getting dragged toward the same value. It is the same thing that happens if you keep replacing numbers with the average of their neighbors: everything slowly flattens out to one common level.

That is exactly what wrecks the classification. The model can only tell the 7 topics apart if papers from different topics end up with different looking vectors. Once deep averaging has smeared everyone toward the same embedding, there is nothing left to separate the classes on, and accuracy drops as $K$ grows. The plot shows this directly.
